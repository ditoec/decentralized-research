## 1. Use of generative AI (required by ESJ, not optional)

ESJ's Artificial Intelligence policy (ijournalse.org/index.php/ESJ/artificial_intelligence, checked 2026-11-27,
"Last updated: October 2026") requires disclosure when a GenAI tool is used beyond spelling and grammar,
"such as generating text, analyzing data, writing code or designing the study". The disclosure goes in two places:

- **Methods:** how the tool was used in the research and how its output was checked.
- **Acknowledgements:** the tool's name and version and its purpose, in the journal's recommended wording.

In this project an AI coding assistant (Claude, by Anthropic, used through Claude Code) wrote most of the code
(`code/trajver`, `code/orchestrator`, `code/program`, the analysis and figure scripts), ran and monitored
experiments on the Sparks and RunPod, and drafted and revised the manuscript text (CLAUDE.md: "Claude works on
the paper"). The model named in this session is Claude Opus 5.5; earlier sessions may have used other versions,
which the authors should check before naming one.

Draft for Methods (adjust to what the authors actually did to check the output):

> An AI coding assistant (Claude, Anthropic, used through Claude Code) wrote most of the experiment and analysis
> code and drafted parts of the text. Its output was checked as follows: the code is covered by unit and
> integration tests; every number in the Results is generated by scripts from the logged runs, each traceable to
> a run identifier in the public repository; references were checked against their primary sources; and the
> authors reviewed the text and the analyses.

Draft for Acknowledgements (the journal's recommended wording, filled in):

> During the preparation of this work, the authors used Claude (Anthropic; [model and version]) in order to write
> experiment and analysis code and to draft and edit the manuscript. After using this tool, the authors reviewed
> and edited the content as needed and take full responsibility for the content of the publication.

The second sentence is an attestation: only the authors can make it. Where: `build_esj_docx.py`, the
`ACK` text in the Declarations (6-x Acknowledgements), and one paragraph in Materials and Methods.

attacks them offline only (no job was sent to a live network). The Discussion says so and has a hidden note to

offer to share the code before publication, and a response window. When it is sent, record the date and the
